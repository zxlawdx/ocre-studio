# Sistema visual

A pesquisa UI/UX Pro Max sugeriu hierarquia compacta, alto contraste, foco visível e poucos elementos decorativos. O Ocre aplica essas escolhas a um editor desktop com painéis compactos, fotografia central e controles identificados por texto. A paleta deriva de pigmentos minerais e segue o tema grafite e ocre da identidade do produto.

A fonte acompanha o sistema operacional e todos os assets funcionam offline. O foco usa o token de acento. O histograma usa cores por canal e rótulos R, G e B. A comparação é ajustável por teclado e pela interface de ponteiro. O canvas oferece zoom e deslocamento sem alterar o arquivo.
